# Metropolis Algorithm Simulation

A comprehensive implementation and analysis of the Metropolis Algorithm using Markov Chain Monte Carlo (MCMC) methods in R. This project studies sampling techniques, convergence behavior, autocorrelation, burn-in analysis, and statistical diagnostics for multiple probability distributions.

## Overview
This project was developed at the Indian Statistical Institute as part of a computational statistics and simulation study. The work explores the theoretical foundations and practical implementation of the Metropolis Algorithm for Gaussian, Exponential, and Bimodal distributions.

The project demonstrates:
- Markov Chain Monte Carlo (MCMC) simulation
- Metropolis sampling algorithm
- Histogram convergence analysis
- Burn-in and thermalization diagnostics
- Autocorrelation analysis
- Jackknife error estimation
- Step size optimization
- Statistical verification using R simulations

## Features
- Generalized Metropolis Algorithm implementation in R
- Gaussian distribution simulations
- Exponential distribution simulations
- Bimodal distribution analysis
- Acceptance rate analysis
- Autocorrelation Function (ACF) visualization
- Jackknife statistical error estimation
- Running mean convergence analysis
- Step size tuning experiments
- High-scale simulations up to 10^8 iterations
